# ROADMAP

## Vision
Куда движется Nantuc и для кого он.

## v1.0.0 — Must
- API freeze: публичный API, deprecation policy, тесты.
- Документировать все способы получения Kernel-компонентов без рефлексии через VmApplication.
- VM: аудит небезопасных мест, fuzz/edge-case тесты, базовые бенчмарки.
- Автоматизация: GitHub Actions workflows, скрипт changelog.
- Документация: правила проектирования системы.

## v1.0.0 — Should
- Улучшить имена/объектную модель классов.
- Полезные директивы препроцессора.
- Extension points для API.

## v1.0.0 — Stretch
- `typedef`.
- Заменяемый парсер.
- Модульный/расширяемый builder.
- Рефакторинг компилятора.

## After v1.0
- `VmApplication.Extension.Vm`:
  - DynamicMethod-реализация;
  - быстрый небезопасный интерпретатор;
  - самописный JIT на C++ через P/Invoke — если вообще будем делать.

## Non-goals
- добавление нового крупного фукнционала в проект 
- изменение сематики методов
